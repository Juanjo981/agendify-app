OBJETIVO
--------
Este documento reemplaza el contrato previo basado en rutas
/profesionales/me/... y consolida un unico contrato vigente alineado al
frontend actual.

RUTAS CANONICAS VIGENTES
------------------------

1) POST /recetas
   Crea receta en estado BORRADOR.

2) GET /recetas/{idReceta}
   Obtiene detalle de receta.

3) GET /pacientes/{idPaciente}/recetas
   Lista recetas del paciente (paginado).
   Query: page, size, sort, estado.

4) PUT /recetas/{idReceta}
   Actualiza receta (solo BORRADOR).

5) POST /recetas/{idReceta}/emitir
   Emite receta.

6) POST /recetas/{idReceta}/versiones
   Crea nueva version PDF desde receta emitida.

7) POST /recetas/{idReceta}/copias
   Crea nueva receta BORRADOR como copia.

8) POST /recetas/{idReceta}/anular
   Anula receta.

9) DELETE /recetas/{idReceta}
   Soft delete (estado ELIMINADA).

10) GET /recetas/{idReceta}/pdf-url
    Devuelve URL firmada temporal del PDF actual.

11) GET /recetas/{idReceta}/versiones/{numeroVersion}/pdf-url
    Devuelve URL firmada temporal del PDF de una version especifica.

NOTAS DE CONTRATO
-----------------
- El frontend NO persiste URLs firmadas de PDF.
- Para listado de versiones no existe endpoint dedicado en backend actual;
  la UI deriva historial desde version_actual y consume pdf-url por version.
- Payloads y responses usan snake_case segun modelos FE en
  src/app/shared/models/recetas.models.ts.

DEPRECACION DE CONTRATO ANTERIOR
--------------------------------
Queda deprecado para frontend el contrato documentado como:
- POST /profesionales/me/pacientes/{idPaciente}/recetas
- GET /profesionales/me/pacientes/{idPaciente}/recetas
- GET/PUT/POST/DELETE /profesionales/me/recetas/{idRecetaMedica}...

Si backend mantiene esas rutas por compatibilidad, deben considerarse alias
legacy y no fuente principal para nuevas integraciones frontend.

VALIDACION FUNCIONAL MINIMA ESPERADA
------------------------------------
- Crear borrador
- Listar recetas por paciente
- Ver detalle
- Emitir
- Crear copia
- Anular
- Obtener PDF actual y por version

---------------
